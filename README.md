# Halo, saya Candra Rudyatmoko 👋

Saya seorang **AI / ML Engineer** dengan latar belakang software engineering sejak sekitar tahun 2010. Kecerdasan buatan bukan hal baru bagi saya — saya memulainya dari ranah yang lebih klasik: jaringan saraf tiruan (LVQ dan Backpropagation) untuk proyek diagnosa penyakit serta kriptografi, dan *decision support system*. Pengalaman itulah yang menjadi bekal ketika dunia AI bergeser ke arah LLM seperti sekarang.

Hari ini saya menekuni **AI engineering** secara penuh — merancang dan membangun sistem berbasis LLM, RAG, dan AI *agents* dari hulu ke hilir: mulai dari arsitektur, inferensi, hingga antarmuka pengguna akhir. Saya tidak terpaku pada satu pendekatan; lokal maupun cloud, saya pilih yang paling sesuai dengan persoalan yang dihadapi. Saat ini saya membangun ekosistem AI di bawah bendera **dataSiberLab**.

### 📌 Sorotan proyek

| Proyek | Deskripsi | Teknologi |
|---------|-----------|-----------|
| [SiberFlow](https://github.com/candrapwr/siberflow) | Platform AI *agent* multi-provider dengan *tool calling*, *sandbox*, dan multi-sesi | TypeScript, Electron, React |
| [SiberGate](https://github.com/candrapwr/sibergate) | *Reverse proxy* & penyeimbang beban untuk provider LLM/gambar/audio | TypeScript, Hono, SQLite, Next.js |
| [SiberLLM](https://github.com/candrapwr/siberllm) | Aplikasi *desktop* untuk menjalankan model LLM lokal lewat llama.cpp | TypeScript, Electron, llama.cpp |
| [SiberRAG](https://github.com/candrapwr/siberrag) | Mesin RAG untuk dokumen berbahasa Indonesia + ekstraksi KTP/paspor | Python, FastAPI, ChromaDB, BGE-m3 |
| [SiberCraft](https://github.com/candrapwr/sibercraft) | *Mockup* & *dashboard* dari bahasa natural di atas kanvas tak terbatas | Node.js, DeepSeek |
| [SiberBoard](https://github.com/candrapwr/siberboard) | Pembangun alur kerja & *flowchart* visual dengan AI *assistant* | JavaScript, esbuild, Tailwind |
